# 도식 Pool — 표 기반 도식화 선택 카탈로그

> 출처: `form/양식(표)/2. 도식 Pool.hwpx` (2024.11, 2단~5단 도식Pool 정의서. 2026-07-22 kordoc 분석).
> **대원칙: 도식화가 필요하면 SVG·이미지를 그리지 않는다.** 이 Pool에서 논리전개 구조에 맞는
> 표 패턴을 선택하고, 본문 내용에서 각 작성란(슬롯)에 들어갈 텍스트를 추출해 표를 채운다.
> 표 템플릿 원형은 위 hwpx 파일에서 발췌한다 (빈 셀 = 작성란).

## 선택 절차 (LLM 판정)

1. 도식화할 내용의 **논리전개 구조**를 판정한다: 도입(배경) 유무 / 전개 항목 수 / 결과가 하나인가 여럿인가 / 강조 대상.
2. 아래 판정표에서 조건이 맞는 패턴을 고른다. 복수 후보면 **단수가 적은 쪽**(단순한 쪽)이 가독성 우선.
3. 슬롯별 입력 텍스트를 본문·근거에서 추출한다 — 셀 텍스트는 명사구 위주로 짧게(1~2행), 본문 문장을 그대로 붙이지 않는다.
4. 게이트①(목차) 단계에서 "이미지 배치/도식 설계" 절에 선택 패턴·슬롯 내용을 함께 제시해 승인받는다.

## 판정표

| 패턴 | 구조 | 선택 조건 (정의서 명시) |
|---|---|---|
| 2단 (2단-1~4) | 전개(추진내용) → 마무리(추진실적) | 배경·목적·원인·문제점 등 도입부가 부실해 3단을 못 쓸 때. **가급적 지양** |
| 3단-1 | 도입 → 전개 → 마무리 | 전개가 프로세스·전개형으로 진행되어 하나의 결과를 도출할 때 |
| 3단-2 | 도입 → 전개 → 마무리 | 추진배경이 3가지로 구분되고 추진내용의 수준이 같을 때 |
| 3단-3 / 3단-4 / 3단-11 / 3단-12 | 도입 → 전개 → 마무리 | 현황·문제점의 원인은 여러 가지인데 성과는 한 가지로 제시 가능할 때 |
| 3단-5 | 도입 → 전개 → 마무리 | 추진배경이 순차 프로세스로 표현되거나, 주요 성과가 전개 전체에 공통으로 제시될 때 |
| 3단-6 | 도입 → 전개 → 마무리 | 배경·내용을 인포그래픽 등으로 추가 설명이 필요할 때 |
| 3단-7 | 도입 → 전개 → 마무리 | 도입부(목적·원인·문제점) 강조 + 추진내용↔추진실적이 1:1 매칭될 때 |
| 3단-8 | 도입 → 전개 → 마무리 | 추진배경을 정부정책·경제현황·국민니즈 등 나열식으로 쓸 때 |
| 3단-9 | 도입 → 전개 → 마무리 | 추진내용이 사실 위주로 분량이 많을 때 |
| 3단-10 | 도입 → 전개 → 마무리 | 사실 위주 분량 많음 + 실적·성과를 한 가지 결과로 도출(결과 강조 시 짙은 음영) |
| 4단-1 | 배경 → 전개 → 실적 (+강조단) | 전개(추진내용) 중 우수사례 등 강조가 필요할 때 |
| 4단-2 / 4단-3 | 배경 → 전개 → 실적 (+강조단) | 4단 전개 변형 (원자력환경공단형) |
| 5단-1 | 배경 → 내용 → 실적 → 우수사례 → 성과 | 추진실적·우수사례 중 전년도 지적사항 개선 반영을 보여줄 때 |

## 부속 자산 (같은 파일 내)

- **일러스트**: 부등호·화살표(흰 바탕용/음영 바탕용), 강화·Tip·참고·질의/답변 아이콘, 방향별 화살표 세트
- **다이어그램**: 격자 배치형, 개선 전→후 비교형(가운데 화살표), 흐름 연결형

## 작성 규칙

- 도식 표도 md-profile 표 규격의 예외가 아니다 — hwpx 주입 시 원형 표 구조(병합 포함)를 도식 Pool 파일에서 복제해 쓰되, md 초안 단계에서는 `도식: {패턴ID}` 마커 + 슬롯 내용 목록으로 표기하고 변환 단계에서 치환한다.
- 슬롯 내용도 팩트체크 대상 — 본문 근거와 불일치하는 텍스트를 도식에만 넣는 것 금지.
