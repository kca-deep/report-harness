## 7. 계층 간격 (원본 바이너리 실측)

> 출처: `form/250609_(표준보고서) KCA 문서 양식.hwp` OLE 스트림 직접 파싱(HWPTAG_PARA_SHAPE 등),
> 2026-07-22 확정. 상세 원자료: claudian vault
> `reports/20260722/1313_하네스-AI성과-관리체계/research/fetched/양식-문단간격/추출결과.md`.

**핵심 발견**: 이 양식은 문단모양(PARA_SHAPE)의 "문단간격 위/아래" 필드를 계층 간격 구현에
쓰지 않는다 — □/ㅇ/-/＊ 등 실제 텍스트를 담은 모든 문단모양은 위/아래 간격이 **전부 0**이다.
대신 **글자크기만 줄인 빈 줄(스페이서 문단)을 계층 사이에 하나씩 삽입**해 시각적 간격을
만드는 방식이다. 즉 "간격 pt"의 정답은 paraPr 여백이 아니라 스페이서 문단의 글자크기다.

| 경계(위 요소 → 아래 요소) | 확정 간격 | HWPUNIT(charPr height) |
|---|---|---|
| 발신 줄 → □ (첫 헤딩) | 8pt | 800 |
| □ → ㅇ | 6pt | 600 |
| ㅇ → - | 6pt | 600 |
| - → ＊ | 3pt | 300 |
| ＊ → 다음 □ (새 블록 시작, 블록 구분) | 15pt (일반 빈 줄) | 1500 |
| ＊ → 표 캡션(`< 표 제목 >`/`[ 표 제목 ]`) | 10pt | 1000 |

- "8pt"는 **모든 □ 앞이 아니라 발신 줄 직후 첫 □ 한정**이다. 이후 반복되는 □(새 블록 시작)는
  8pt가 아니라 15pt 일반 빈 줄(블록 구분)이다.
- 발신 줄 정렬은 **오른쪽(우측)** 확정(paraShapeID=17, 속성1 정렬비트=2) — R012(`<right>` 래핑).
- `skills/report-pipeline/scripts/postprocess_hwpx.py --spacing`이 이 표의 확정값으로 kordoc
  `generate_document` 산출물(스페이서 문단이 없는 상태)에 스페이서 문단을 삽입해 재현한다(R013).
- ☞ 결론 유도 기호의 인접 간격은 ※·＊ 준용 3pt(R025). 제목 박스 상단여백은 postprocess가
  앵커 문단 줄간격 100% 치환 + 표 outMargin top 0으로 제거한다(R022 개정 '26.7.24) —
  **상단 얇은 행(3.8pt)은 양식 원형(1열×3행)의 그라데이션 배경 밴드이므로 삭제 금지**
  (양식 OLE 실측: 0행 3.8pt 그라데이션 채움·1행 제목·2행 3.8pt 4변 실선 밑줄).
