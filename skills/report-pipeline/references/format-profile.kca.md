> `{state_dir}/format-profile.{기관}.md`를 생성해 이 시드 대신 사용한다.

## 3. 계층 기호 체계

```
□ 1단 — 절 제목 (HY헤드라인M 15pt)
 ㅇ 2단 — 요지 (휴먼명조 15pt)
   - 3단 — 상세 (휴먼명조 15pt)
＊ 참고·각주 (맑은고딕 13pt)
※ 참조 표기 (본문 내 안내)
```

## 4. 문서 골격

1. 표지(제목 표 + 연월 `2025. 6.` + 기관 로고) — 표지 있는 보고서의 경우
2. 본문 제목 (HY헤드라인M 20pt)
3. 발신정보 `< '연. 월. 일.(요일), 본부 팀 >`
4. □/ㅇ/- 개조식 본문 (+ 표·도식)
5. 참고N 블록 (HY헤드라인M 16pt 헤더 표) — 필요 시
6. 붙임 목록

## 5. 서술량·줄바꿈 (실보고서 코퍼스 분석 반영)

- ㅇ·- 항목의 서술량: **최대 2줄** (사용자 명시 규칙). 2줄 초과 시 하위 계층으로 분리하거나 문장을 나눈다.
- 상세 수치·빈도 관례는 `style-guide.md`의 코퍼스 분석 결과를 따른다.
