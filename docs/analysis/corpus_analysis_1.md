## 4. 조사·표기

**관찰**
- **명사형 종결이 절대 다수**: ~구축, ~지원, ~필요, ~예정, ~제공, ~검토, ~추진, ~마련, ~조성, ~심화, ~초래, ~가능, ~향상. "~함/~임" 종결은 극히 드묾 — 코퍼스 전체에서 "도달하지 못한 상황임"(250526) 1건 수준. 즉 **"~함" 개조식이 아니라 명사(동작명사)로 끊는 개조식**.
- 빈도 순 체감: ~지원·~제공 > ~필요 > ~구축·~마련 > ~예정 > ~검토 > ~추진 > ~가능.
- 조사 생략: 괄호 리드 직후 주어 조사 생략("(목적) KCA 모든 부서의…"), 목적격 조사는 대체로 유지, "및"·"등"·가운뎃점(·, ‧, ꞏ)으로 병렬 압축.
- 날짜: 아포스트로피 연도 축약이 표준 — "'25. 4. 8.(화)", "'25. 3. 10(월) \~ 14(금)", "('24.12월)", "('25.6월\~12월)", "(4.23)". 요일 병기는 헤더·일정에, 월 단위는 "'25.6월" 붙여쓰기.
- 수치·단위: "$20/월", "$300/년", "약 3.2백만원/연", "79만원/월", "6백만원", "총 7,130,000 원", "약 56.7%", "36.3억". 원화는 백만원·만원 축약과 콤마 전액 표기 혼용. 단가 산식 병기 관례: "6백만원 = (30만원/시간 × 4시간) × 5회" (250225).
- 근거 병기: 지시·출처를 문미 괄호로 — "(5.19 기관장지시사항)"(250526), "(5.29 기관장 지시사항)"(250612 웍스AI), "(6.10 기관장 지시사항)"(심층리서치 일정).

**인용 예시**
- "○ 지방본부에 한하여 ChatGPT 서비스 이용 구독 계정 지원 필요" — 250408 (~필요 종결)

**관찰**
- 맺음 절의 표준은 **"□ 향후계획(또는 향후 계획/향후 일정)"** + "○ 할일 : 날짜" 목록. 콜론 뒤 날짜, 기간은 "\~" 사용.

  - 계획·방안형 → 향후계획 절로 종결 (250409, 250512, 250521, 250529 보고1)
  - 조사·검토형 → "시사점"(250408) 또는 "도입방안 검토"(250526) 같은 **판단 절**로 종결하고 향후계획 생략, 곧장 붙임으로.
  - 순수 정보조사형(250529 보고2·보고3, 250425) → 판단 절도 없이 본문 종료 또는 붙임 전환. 관례적 인사말·맺음 문구("보고를 마칩니다" 류)는 전무.
  - 대형 계획서(250225) → "Ⅵ. 추진일정 및 소요예산"(간트형 일정표 + 소요예산 산식)으로 종결.
- 행정사항·건의 절은 이 코퍼스에는 미출현. 협조 요청은 ※로 처리: "※ 보고 일정에 따라 차순위 부서는 1층 영상회의실 앞 대기 협조 요청" (심층리서치 일정 문서).

## 6. 붙임

**관찰**
- 붙임 표기는 본문 말미에 **음영 박스형 제목 줄**로 삽입: `| 붙 임 |  | 제목 |` (단수) 또는 `| 붙임 1 |  | 제목 |`, `| 붙임 2 |  | 제목 |` (복수). "붙 임"으로 띄어 쓰는 경우(250408, 250512, 250521)와 "붙임 N"(250425) 병존.
- 별도 문서가 아니라 같은 파일 안의 후속 페이지로 이어짐.
- 붙임으로 넘기는 내용 = **전수 데이터와 상세 비교**: ① 부서별 구독현황 전수 표(250408), ② 참석자 28명 명단(250521), ③ 온프레미스 vs 클라우드 TCO 상세·경량 LLM 3종 비교(250425), ④ 프로토타입 화면 캡처(250512). 본문에는 요약 표·결론만 두고 검증용 원자료를 붙임으로 분리하는 분담.
- 본문→붙임 참조는 ※ 한 줄: "※ 세부내용은 붙임 참조" (250408). 참조 없이 붙임만 두는 문서도 있음(250425, 250521).

**인용 예시**
- "※ 세부내용은 붙임 참조" → "| 붙 임 |  | 생성형AI 구독현황 |" (부서·정원·도구·요금제 8열 전수 표) — 250408
- "| 붙임 1 |  | 온프레미스 및 클라우드 구축 비교 | … | 붙임 2 |  | 경량 LLM 모델 비교 |" — 250425
- "| 붙 임 |  | 부서별 참석자 명단(28명) |" — 250521

**빈도**: 붙임 보유 = 다수(12건 중 4건+) / 박스형 붙임 제목 = 붙임 보유 파일 전부 공통 / "※ … 붙임 참조" 명시 = 소수

## 7. 표 사용

**관찰**
- 표 제목 관례는 **[ 대괄호 ]가 우세**: "[ AI 커뮤니티 운영방안 ]", "[ 전직원 대상 AI 리터러시 맞춤형 교육(안) ]" (250225), "[ AI 에이전트와 생성형AI 비교 ]" (250526), "[ Gemini 2.5 모델 ]", "[ 콘텐츠 생성형 AI ]" (250529 보고3), "[ 생성형AI Work-Flow ]" (250512). **< 꺾쇠 >도 병용**: "< 2025년 OpenAI사 ChatGPT 최신모델 현황 >" (250529 보고1), "< 영상 회의 보고 >" (심층리서치 일정), "< 추진방향 >" (250225 박스). 제목 없이 본문 직후 바로 표를 두는 경우도 다수(250408 구독현황, 250425 모델 스펙).
- 표를 쓰는 상황: ① 다항목 비교(모델·요금제·경쟁사·AS-IS/TO-BE), ② 현황 전수 나열(구독현황·명단), ③ 시간표·간트 일정, ④ 교육 커리큘럼. 나열 3개 초과 + 속성 2개 이상이면 표 전환이 관례.
- 열 수: 본문 표 3~5열이 주류(비교표 4열, 스펙표 5열), 붙임 전수 표는 6~8열까지. 첫 열 헤더는 "구 분"(띄어쓰기 포함) 표기 관례.
- 셀 안에서도 개조식 유지: "○" 또는 "-" 불릿, "•" 사용(250225 정책 박스, 250529 보고1 모델표).

**인용 예시**
- "< 2025년 OpenAI사 ChatGPT 최신모델 현황 > | 구 분 | GPT-4.1\* | OpenAI o3 | OpenAI o4-mini |" — 250529 보고1 (꺾쇠 제목 + 구 분 헤더 + 4열 비교)
- "| 구분 | 대형 LLM | 경량화 LLM |" (파라미터수/학습 데이터/하드웨어 요구/활용분야/추론속도 행) — 250425 (제목 없는 3열 비교표)
- "[ AI 에이전트와 생성형AI 비교 ] | 구분 | 사용범위 | 작업계획 | 연속성 | 외부연계 | 정확성 | 확장성 |" — 250526 (대괄호 제목 + 7열)

**빈도**: 표 자체 = 전 파일 공통(12건 전부 1개 이상) / [ ] 제목 = 다수 / < > 제목 = 소수 / "구 분" 첫 열 = 다수

## 8. 제목·헤더

**관찰**
- 문서 제목 = **"주제 + 문서유형 명사"** 패턴. 유형 명사 어휘: 실행계획 / 결과 및 구독 지원 / 방안 / 검토결과 / 추진(안) 보고 / 계획(안) / 보고(안) / 개정(안) / 조사 보고 / 검토(안) / 검토 보고 / 일정(안). **(안)** 접미가 매우 빈번(미확정 문서 표지).
- 파일명에는 버전·상태 태그(v0.2, v1.0, 최종★, 원장님보고)를 붙이지만 문서 내 제목에는 넣지 않음. 파일명 제목과 문서 내 제목이 다른 경우도 있음(250512 파일명 "기관 홍보영상 제작(안)" vs 내부 제목 "KCA 영상제작 플랫폼 추진(안) 보고", 250526 파일명 "_검토" vs 내부 "보고(안)").
- **발신정보 줄 = 전 단신 보고 공통 관례**: 제목 바로 아래 `< '25. 4. 9.(수), 경영기획본부 AI디지털심화팀 >` — 꺾쇠 안에 "축약연도. 월. 일.(요일), 본부명 팀명". 파일명 날짜(작성 시작일)와 발신 날짜(보고일)가 다른 경우 존재(250425 파일 → 문서 4.28, 250612 웍스 → 6.16).
- 표지형 계획서(250225)만 발신정보 대신 표지(비전 슬로건 인용문 + "2025. 3." + 기관명)와 목차 페이지 보유.
- 절 제목 어휘 목록(출현 순): 추진배경/추진 배경, 검토 배경, 배경, 개요, 현황 및 문제점, 조사결과, 시사점, 개선방안, 주요 내용, 세부내용, 모델별 세부 내용, 경량화 LLM 모델 특징, 인프라 구현 방안, 비용 분석, 활용 사례, 국내 사례, 해외 사례, 도입방안 검토, 향후계획/향후 계획/향후 일정, 교육 과정, 보고 일정(안), (계획서) 우리의 현 주소, 비전 및 추진전략, 추진내용, 추진체계, 추진일정 및 소요예산.
- 전형적 절 흐름: **배경(왜) → 현황·세부내용(무엇) → 시사점·검토(판단) → 향후계획(다음) → 붙임(근거)**.

**인용 예시**
- "KCA AI 서비스 실태조사 결과 및 구독 지원 / < '25. 4. 8.(화), 경영기획본부 AI디지털심화팀 >" — 250408
- "네이버 경량화AI 모델(HyperClova X Seed) 검토결과 / < '25. 4. 28.(월), 경영기획본부 AI디지털심화팀 >" — 250425 (파일명 날짜 4/25와 상이)
- "'AI를 가장 잘 활용하는 공공기관으로 도약'을 위한 2025년 AI KCA 일상화 실행계획 / 2025. 3. / 한국방송통신전파진흥원" — 250225 (표지형)

**빈도**: 발신정보 꺾쇠 줄 = 단신 보고 11건 전부 공통 / (안) 접미 = 다수 / 표지+목차 = 소수(대형 계획서만)
