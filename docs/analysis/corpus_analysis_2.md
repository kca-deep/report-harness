## 2. 줄바꿈·서술량

**관찰**
- ㅇ 항목: 원칙적으로 **한 문장 1건**, 인쇄 기준 1~2줄(대략 40~90자). 3줄을 넘기지 않고, 길어지면 `-` 하위 항목이나 ※로 분리. [전 파일 공통]
- `-` 항목: 1~2줄 한 문장. ㅇ보다 짧거나 비슷한 길이의 보충 설명. [전 파일 공통]
- ※/\* 항목: 1줄 내외의 참고·예외·각주. 본문 문장에 넣기 애매한 조건·출처·예시를 흡수하는 역할. [전 파일 공통]
- 줄바꿈 지점: 문장 중간 개행보다 "~및", "~통한", "~따라" 연결어로 한 문장을 이어가다 명사형 종결에서 끊음. 여러 사실을 나열할 때는 문장을 늘리지 않고 표로 전환. [다수]
- 예외: 붙임의 회의결과 상세(250820)에서는 ○/- 항목이 3~4줄까지 늘어남 — 본문과 붙임의 서술 밀도가 다름. [소수]

## 3. 계층형 구조

**관찰**
- 기본 단수: **□(절) → ㅇ(요지) → -(상세) → ※·\*(참고/각주)**. [전 파일 공통]
- 변형: 251208은 ㅇ 대신 ○ 사용(동일 역할). 250826·251223은 □ 아래에 `[1] [2] [3]` 숫자 중간 섹션을 두는 3단+α 구조. 붙임·표 내부에서는 ①②③, ⦁, ∙, ․ 등 별도 기호. [소수]
- 역할 분담: □=절 제목(개요/배경/내용/계획), ㅇ=핵심 요지 한 문장, -=근거·방법·세부, ※=예외·전제·출처, \*=용어·항목 각주(문장 뒤 \* 표시 후 하단 풀이). [전 파일 공통]
- 괄호 리드 "(키워드)": ㅇ 항목 선두에 매우 빈번. 요지의 주제어를 2~5자로 압축 — "(목 적)", "(일 정)", "(직위신설)", "(GPU서버 구매)", "(사 업 명)", "(조사대상)". 2음절 리드는 사이 공백으로 자간 정렬("일 정", "장 소"). `-` 항목에도 간혹 사용 — "- (서버사양)", "- (CAIO)". [전 파일 공통]

**인용 예시**
1. "□ 추진 배경 / ㅇ (목 적) AI의 폭발적 진화 및 정부 AI 활용 정책 활성화에 따라 … / ㅇ (추진 경과) 총 4차 …" — 250820 (□→ㅇ+괄호리드)
2. "[1] 도메인 지식 정비 / ㅇ (문헌 정비) … / - 본사·지방 주니어 대상 … 취합 후 데이터 전처리" — 250826 (□ 아래 [n] 중간 섹션)
3. "○ (역할 규정) 과제 추진 시 업무 혼선 방지, … 부서 간 역할을 명확히 구분" — 251208 (○ 변형)
4. "- (CAIO) 정부 AI정책과 기관 전략을 연계, … 부서장 중 원장이 지명하여 임명 / ※ CAIO가 특정업무(계획수립, 예산검토 …) 담당 BAIO에게 업무협력 요청 및 실행" — 250714 (-에도 괄호리드, ※ 보충)
5. "\* Knowledge & Certification Assistant – Intelligent : 지능형 지식·자격 업무지원시스템" — 250826 (\* 각주 풀이)

## 4. 조사·표기

**관찰**
- 개조식 조사 생략: 목적격 조사(을/를)와 주격 조사를 자주 생략하고 명사구를 직접 연결 — "LLM 모델을 활용 업무망 서비스 구현"(을 생략+동사 명사화), "조달청 나라장터 종합쇼핑몰 GPU서버 구매 추진". 단, 문장 흐름상 필요한 조사(으로, 통한, 위한, 따라, 대비)는 유지. [전 파일 공통]
- 명사형 종결어미 분포(본문 기준): **동작명사 종결(~구축/~추진/~마련/~수립/~제공/~실시/~완료/~확보/~향상)이 압도적 다수**. "~필요"도 빈번(배경·문제점 절). "~가능"(검토 결과 절). "~예정", "~중"은 주로 ※·괄호·붙임 회의록에서. "~함/~임" 종결은 본문에서는 드물고 붙임 회의록·서술형 설명에 국한("~답변함", "~존재함", "~과제임"). [전 파일 공통]
- 날짜: 연도는 아포스트로피 축약 "’25.", 형식은 "’25. 6. 27(금)", "’25. 7. 21.(월)", "'25.3월", "9.19", "12.29(월)", 기간은 물결 "‘26. 1. 13(화) ~ 1. 23(금)", "9월~11월". 요일 괄호 병기 관례. [전 파일 공통]

- 가운뎃점(·, ‧) 병렬 나열: "수립‧실행·관리", "규정·매뉴얼" — 쉼표 대신 가운뎃점이 기본. [전 파일 공통]

## 6. 붙임

**관찰**
- 붙임 헤더는 표(셀 박스) 형식: `| 붙임 1 | | 제목 |` — 페이지 새 절 머리에 박스로 배치. 붙임이 1건이면 "붙 임"(공백 자간). [다수 — 붙임 있는 7건 전부]
- 붙임으로 넘기는 내용: ① 회의결과·과제별 상세(250820 — 본문은 선정 결과 요약, 3차례 회의록 전체는 붙임), ② 시스템 화면 캡처·아키텍처(251223, 250908_FoodCast), ③ 서식·체크리스트·설문양식(251208, 260112), ④ 검증 세부 데이터(251223 붙임2 품질검증), ⑤ 제품 소개자료(250722 NHN Dooray). 본문=판단·요약, 붙임=원자료·양식 분담. [다수]
- 본문에서 붙임 참조: "(붙임2 수요조사서)" 식 괄호 참조(260112). "※ 상세는 붙임N" 정형구는 이 코퍼스에서는 미출현 — 참조 없이 붙임 헤더만 두는 경우가 더 많음. [소수]

**인용 예시**

## 7. 표 사용

**관찰**
- 표 제목은 **대괄호 `[ 제목 ]` 형식이 표준**이며 표 상단 중앙의 박스 캡션으로 배치 — "[ 추진 방향 ]", "[ AI 운영모드 요약 ]". < > 꺾쇠 형식은 이 코퍼스에서 미출현. [다수 — 표 캡션 있는 파일 전부]
