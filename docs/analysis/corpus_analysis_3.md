## 1. 톤앤매너

**관찰**
- 전 문서 공통으로 객관·건조한 관청 개조식. 감상적 수식어·평가 형용사 거의 없음. 주어(기관·작성자)는 생략되고 사업·시스템·기능이 문두에 옴. 지시 근거는 문미 괄호로 처리 — "(기관장 지시사항, '25.1.3)".
- **굵게(볼드) 강조가 핵심 관례**: 요약보고 8종 전부에서 ㅇ 항목의 핵심 명사구 단위로 굵게 처리. 문장 전체가 아니라 '결론 키워드'만 선별 강조. RFP 본문(요구사항 카드)은 볼드를 거의 안 쓰고 절 표제(□)만 굵게.
- 보조 기호 강조: ※(참고·조건 부기)는 전 파일 공통, ☞(결론·귀결 유도)는 소수 파일, ★·색상 강조는 파싱 텍스트상 미확인. 표 내 불릿은 ∙/·/‧, RFP 내 ▲·‣ 나열도 등장.
- 능동 서술이되 행위주는 숨김: "AI가 직접 검색·분석", "자동 변환" 등 기능 주어화.

## 2. 줄바꿈·서술량

**관찰**
- ㅇ 항목 = **한 문장**으로 완결. 인쇄 기준 1~2줄(원문 텍스트 40~90자)이 지배적. 3줄 이상 넘어가는 ㅇ은 예외적(과제카드 ④환류 1건 정도).
- - 항목 = 부연 1문장, 역시 1~2줄. -가 2개 이상 연달아 붙는 경우도 각각 독립 1문장.
- 줄바꿈은 문장 중간에서 일어나지 않음(자동 워드랩에 맡김). 한 항목 = 한 문장 = 한 단락. 개조식이므로 마침표 없이 명사형으로 끊음.
- 문장 길이 경향: 관형절을 겹쳐 길게 끌고 가되("~을 통해 ~하여 ~하는 ~ 구축") 한 문장 안에서 완결. 두 문장으로 쪼개지 않고 쉼표·'및'·'·'로 압축.
- RFP 요구사항 세부내용은 □/-/ㅇ 불릿당 "~하여야 함" 1문장씩 나열, 항목당 1~3줄.

**인용 예시**
- "ㅇ FURIOSA의 RNGD\*를 LG의 EXAONE 4.0 모델 및 ixi-Enterprise 플랫폼과 통합한 온프레미스 AI 환경 제공" [Sovereign] — ㅇ 1문장 1줄, 상세는 각주(\*)로 탈출
- "ㅇ AI를 활용한 경영평가 연중 상시 관리체계 전환을 통한 근거 소실·실적 누락·작성부담 해소 등 전사 과제 추진(기관장 지시사항 5.18)" + "- 과제관리카드를 매월 관리하여 8할을 사전 완성하고 차년도 개선과제로 환류(PDCA)를 적용한 '경평보고서 살아있는 초안'으로 재정의" [과제카드] — ㅇ 요지 1문장 + - 부연 1문장의 짝
- "- 지원 요약서 취합(550분 : 5분x110개) + 방송콘텐츠 제작역량 평가결과 비교(550분 : 5분x110개) + 제작지원 사업 최종평가 결과 확인 등(100분)" [OCR] — - 레벨에서 수식으로 압축, 문장화 회피
- "ㅇ 전국부서장 전략회의 운영체계 전사 공유 및 순차교육 실시('26.7월)" [과제카드] — 향후계획 ㅇ은 1줄 고정

**빈도**: ㅇ·- 1문장 2줄 이내 = 전 파일 공통(요약보고 기준), 초과분은 각주(\*)·※·표로 분리하는 회피 패턴도 전 파일 공통

## 3. 계층형 구조

**관찰**
- 기본 위계: **□ → ㅇ(또는 ○) → - → ※/☞/\*** 4단. 표 내부에서는 ∙/·/‧ 불릿과 ①②③ 원문자, ▲·‣(RFP) 사용.
- ㅇ와 ○ 혼용: 구형 문서([GPTs], [네이버웍스])는 ○, 이후 문서는 ㅇ. RFP는 □(표제)—○/ㅇ—- 병용.
- 역할 분담: □=절 제목(추진배경/주요 내용/기대 효과 등) 또는 RFP의 항목 표제(□ 사 업 명 : …), ㅇ=요지 1문장, -=상세·근거·수단, ※=조건·참고·예외, \*=용어 각주(항목 직하단에 "\* (레니게이드) FURIOSA 의 2세대 NPU(추론 가속기)" 식), ☞=귀결·결론.
- **괄호 리드 "(키워드)" 패턴이 ㅇ 레벨의 표준**: 볼드와 결합해 "(**호환성**)", "(**목 적**)" 형태. 항목 분류어(목적/문제점/방식)와 전략명(①작성, ②월별 종합점검) 모두 사용. 2글자 리드는 "(목 적)", "(일 시)"처럼 벌려 씀.
- RFP는 상위에 장(Ⅰ~Ⅵ) + 절(1,2,3) 배너 표 구조를 얹고 그 아래 □/ㅇ/- 재사용.

**인용 예시**
- "ㅇ (**호환성**) 냉각 설비 교체 없이 표준 데이터 센터 랙(15kW 공랭식)에 즉시 설치 가능하고…" / "ㅇ (**효율성**) GPU 클러스터 대비 소유비용(TCO) 30% 절감" / "ㅇ (**보안성**) 외부 인터넷 연결 또는 클라우드 API 호출 불필요" [Sovereign] — 괄호 리드 3연속 병렬
- "ㅇ **(목 적)** AI디지털심화팀에서 **사전 개발\*한 프로덕션(약 90%) 대상**…" / "ㅇ **(일 시)** '26년 3월 5일(목) \~ 19일(목)" / "ㅇ **(방 식)** **개인노트북**으로 **이론·실습 병행**" [해커톤] — 2글자 리드 벌려쓰기
- "ㅇ (**①작성, Claude Project**) 과제별 전용 AI작업공간…" → "- 'Notion MCP'로 카드를 조회·갱신하며…" → "※ AI 활용이 익숙하지 않은 일부 담당자는…" [과제카드] — ㅇ→-→※ 3단 전형
- "○ **(메시지 요약)** 네이버 생성형AI(하이퍼클로버X)를 통해…" [네이버웍스] — ○ 계열 + 괄호 리드
- "\* (레니게이드) FURIOSA 의 2세대 NPU(추론 가속기)" [Sovereign] — \* 각주 단

**빈도**: □→ㅇ→- 위계 = 전 파일 공통 / 괄호 리드 = 다수(7/10; GPTs·RFP류는 절제) / \* 각주 단 = 다수 / ①② 원문자 나열 = 다수(표·RFP 후보목록 등)

## 4. 조사·표기

**관찰**
- 개조식 조사 생략: 주격·목적격 조사를 자주 생략하고 명사 나열 + '·'(가운뎃점) 병렬로 압축 — "근거 소실·실적 누락·작성부담 해소". 단 관형절 내부 조사('~을 통한', '~를 위한')는 유지.
- 종결어미 분포: 요약보고 본문은 **명사형 종결이 압도적**(제공/구축/수행/제고/확보/검토/추진/재정의/최소화/단축). "~예정"([LGCNS] "공개 예정", "수행 예정"), "~가능"([Sovereign] "설치 가능"), "~필요"([RFP-Agent] "구축 필요") 순. "~함/~임/~음" 종결은 요약보고에선 드물고 **RFP에서 지배적**("~하여야 함", "~해야 함", "~할 수 있어야 함", "~사업임"). "~중" 종결은 미관찰.
- 날짜: 아포스트로피 연도 축약 + 온점 구분 + 요일 괄호 — "'25. 2. 25.(화)", "'26.2.5", "'26.7월", "3.5.(목)", "2.27\~28"(월.일 범위, 물결). 연도만 쓸 땐 "'27년 준공".
- 수치·단위: 천 단위 콤마("255,750,000원(VAT포함)"), 한국식 큰수 단위("약 76백만원/년", "11천원/월"), 배수("2.25배", "3.75배"), 퍼센트 병기("137명(23.7%)"), 근사 접두 "약". 범위는 \~.

**인용 예시**
- "ㅇ (**적용결과**) 사업자 제출서류 취합, 기초자료 비교·확인 등의 자동화로 **서류평가 참고자료 작성시간**을 **약 20시간 단축**" [OCR] — 명사형 종결 + 약/단위
- "ㅇ (**파주 AIDC 구축**) '27년 준공 예정, 수도권 최대 규모(200MW)로 **GPU 최대 12만 장 수용**…" [LGCNS] — ~예정 + 수치 표기
- "◇ **네이버웍스 코어** 최상위 플랜(Standard Plus, 11천원/월) 요금제 사용 시에만 Works AI 활용 가능 (연간 계약 시, 580명 기준 **약 76백만원/년**)" [네이버웍스] — 천원/백만원 단위
- "< '25. 3. 17.(월), 경영기획본부 AI디지털심화팀 >" [네이버웍스] — 날짜 표기 표준형
- "□ 최신 운영체제(OS) 및 하드웨어에 종속되지 않고 운영이 가능해야 함" [RFP-Agent PER-006] — RFP '~함' 종결
- "※ 본 사업은 … 소프트웨어사업 영향평가를 미리 실시한 사업임" [RFP-Agent] — '~임' 종결

**빈도**: 명사형 종결(요약보고)·'~함' 종결(RFP) 분업 = 전 파일 공통 / '·' 병렬 압축 = 전 파일 공통 / 아포스트로피 연도 = 전 파일 공통

## 5. 맺음말

**관찰**
- 요약보고의 마지막 절은 세 계열: ①**향후 일정/향후계획**(일정 병기 ㅇ 나열) ②**기대 효과** ③**주요 시사점**(동향보고). '행정사항'·'건의' 절, 의례적 마무리 문구("~하고자 함" 등)는 이 코퍼스에 없음 — 계획·시사점 나열로 뚝 끊고 붙임으로 넘어감.
- 향후계획 ㅇ는 "실시('26.7월)", "정착(\~12월)"처럼 **문미 괄호에 시점**을 박는 것이 관례.
- 동향(정보)보고 2종은 실행계획 없이 "□ 주요 시사점" 1~수 개 항목으로 종료.
- RFP는 맺음말 대신 "□ 관련 문의"(담당자 실명·전화·메일) → 입찰 안내 → 별지 서식 순으로 종료.

**인용 예시**
- "□ 향후 일정 / ○ 경영관리ㆍ주요사업 담당부서 응답 품질 테스트 : 2.27\~28 / ○ GPTs 응답 피드백 및 프롬프트 보완 : 3.4\~3.5" [GPTs]

- "□ 향후계획 / ㅇ 방송미디어본부 요청에 따라 '**해외진출형 기획개발 지원**', '**K-다큐 투자설명회**' 사업 등의 **참고자료 작성** **확대 적용**" [OCR]
- "□ 주요 시사점 / ㅇ **국산 AI 모델**(LG EXAONE)·**국산 NPU**(FURIOSA RNGD)·**국내 IT 서비스**(LG CNS AgenticWorks)를 결합한 **풀스택 소버린 AI 전략의 대표 사례**" [Sovereign] — 시사점 단독 종결

**빈도**: 향후일정/계획 종결 = 다수(4/8 요약보고) / 시사점 종결 = 동향보고 전부(2/2) / 기대효과 절 보유 = 3/8 / 의례적 마무리 문구 = 전무(전 파일 공통)

## 6. 붙임

**관찰**
- 붙임 배너는 **3열 배너 표**(음영 셀 추정): "| 붙임 1 | | 제목 |". 붙임이 하나뿐이면 "붙 임"으로 벌려 씀. 번호는 '붙임 1', '붙임1' 혼재.
- 붙임으로 넘기는 내용: **화면 캡처·UI 시연**(과제카드, OCR, GPTs 테스트 화면), **전문 자료 원문**(GPTs 프롬프트 전문), **출처 목록**(LGCNS 뉴스기사 URL 표) — 즉 본문은 요지·판단, 붙임은 증빙·원자료·시각자료 담당.
- 본문 내 "※ 상세는 붙임N" 식 명시 참조는 이 코퍼스에서 미관찰 — 붙임 배너를 본문 말미에 직접 이어붙이는 방식.
- **[RFP-GPU]는 그 자체가 기안문의 붙임3**: 기안 본문에는 구매 요지만 남기고, 규격서·평가기준·입찰조건·별지서식 전체(수십 페이지)를 붙임 문서가 전담. 즉 '본문=결재용 요약, 붙임=집행용 완결 문서'의 분담. RFP 내부에도 [별지 서식](제출용 양식), [별첨](기준·특약), [붙임 1~4](계약서·서약서) 3종 위계가 별도로 존재.
- 붙임 내부도 □ 절 구조를 재사용: "□ 과제관리카드 (주요사업 DB, Notion)" [과제카드 붙임].

**인용 예시**
- "| 붙임 1 |  | 경영평가 GPTs 프롬프트 | … | 붙임 2 |  | GPTs 응답품질 테스트 |" [GPTs] — 복수 붙임 배너
- "| 붙 임 |  | 경영평가 과제관리카드 AI 활용 사용자 화면 |" [과제카드] — 단일 붙임 '붙 임' 벌려쓰기
- "| 붙임1 |  | 참고 뉴스기사 목록 |" + "| No | 기사 제목 | 매체명 | URL |" [LGCNS] — 출처 목록의 붙임 이관
- "| 붙 임 |  | 자체LLM을 활용한 평가자료 자동화 플랫폼 |" 이하 화면 캡처 6종 표 배치 [OCR]
- "[별지 제1호] 정보 비공개 동의서 … [붙임 3] 보안 서약서" [RFP-GPU]/[RFP-Agent] — 별지/별첨/붙임 위계

**빈도**: 붙임 배너 표 형식 = 붙임 보유 파일 전부(5/5) / 화면·원자료·목록의 붙임 이관 = 다수 / "상세는 붙임N" 문구 = 미관찰(0/10)

## 7. 표 사용

**관찰**
- 표 제목 두 계열 공존: **< > 꺾쇠형**("< RNGD(레니게이드) 성능 검증 실적 >", "<참고> …", "< 누출금지 정보 >")과 **[ ] 대괄호형**("[ 경영평가 AI 운영체계(안) ]", "[ 핵심 AI 기술 적용 내역 ]", "[ AI Agent 구축 수요조사 결과 ]"). 꺾쇠는 참고·근거 박스, 대괄호는 본문 개념도·집계표 캡션에 기우는 경향.
- 표를 쓰는 상황: ①비교(AS-IS/TO-BE, 요금제·플랜 비교) ②집계·목록(수요조사 결과, 기사 목록, 요구사항 목록) ③일정(회차/일시/주제/핵심 목표, 보고 유형/시기/방법) ④매트릭스형 근거(기술/적용 내용/효과) ⑤RFP 고정 서식(요구사항 카드: 분류/고유번호/명칭/상세설명(정의·세부내용)/산출물/관련요구사항 5~6행 라벨-값 표를 90건 반복).
- 열 수: 본문 표는 **2~4열이 지배적**(구분+내용(+효과/비고)). 기대효과 표 4열, 교육일정 4열, 기사목록 4열. 5열 이상은 RFP 평가배점표 등 행정 서식에 한정.
- 헤더 셀 2글자 벌려쓰기 관례: "구 분", "효 과", "기 타", "배 점", "역 할".
- 절 제목·붙임 배너 자체도 3열 표로 구현(음영 배너) — 표가 레이아웃 장치를 겸함.

**인용 예시**
- "| 구분 | AS-IS (수작업) | TO-BE (자동화) | 효과 |" (①작성시점~⑨환류 9행) [과제카드] — 비교표 4열
- "[ 핵심 AI 기술 적용 내역 ] | 기술 | 적용 내용 | 효 과 |" [OCR] — 대괄호 캡션 + 3열 + '효 과' 벌려쓰기
- "< RNGD(레니게이드) 성능 검증 실적 > | 구분 | 성능 검증 실적 |" [LGCNS]/[Sovereign] — 꺾쇠 캡션 2열(동일 표 재사용)
- "| 회차 | 일시 | 주 제 | 핵심 목표 |" [해커톤] — 일정표 4열
- "| 구분 | KorDoc (문서 파싱) | Korean Law MCP (법령 검색) |" (핵심 기능/적용 내용/효 과/기 타) [MCP] — 2대상 비교 3열
- "요구사항 분류/요구사항 고유번호/요구사항 명칭/요구사항 상세설명(정의·세부내용)/산출물/관련요구사항" 카드 표 [RFP-Agent] — 90건 반복 고정 서식

**빈도**: 표 다용 = 전 파일 공통(10/10) / < > 캡션 = 다수 / [ ] 캡션 = 다수(RFP-Agent·OCR·과제카드) / 2~4열 = 다수 / 헤더 벌려쓰기 = 다수

## 8. 제목·헤더

**관찰**
- 문서 제목 = 명사구 종결, 문서 성격 접미가 규칙적: "~방안 보고(원장님)", "~검토결과 (보고)", "~구축·운영 계획(안)", "~결과 보고", "~추진 계획", "~활용방안 검토 보고", "제안요청서". 대상(수신)이 있으면 괄호 병기 "(원장님)". 파일명에는 YYMMDD 접두와 버전(v0.1, v2, v6) 관리.
- 발신정보는 제목 바로 아래 **"< 날짜(요일), 본부 팀명 >"** 한 줄 — 요약보고 8종 전부 동일 형식: "< '26. 3. 31.(화), 경영기획본부 AI디지털심화팀 >".
- 절 제목(□) 어휘 목록: 추진 배경 / 개 요 / 주요 내용 / 추진 방안 / 추진 내용 / 추진 배경 / 서비스 구성 / 이용 요금 및 제공 기능 / 검토·도입 방안 / 교육 일정 / 기대 효과 / 향후 일정·향후 계획·향후계획 / 주요 시사점. 2글자 절 제목은 "개 요"처럼 벌려 씀. 전개 순서는 대체로 [배경→내용/방안→(기대효과)→향후계획] 또는 [개요→주요 내용→시사점].
- RFP 헤더: 표지(사업명+연월) → 공정거래 준수 안내 → 목차 → 장 배너 "| Ⅰ | | 사업개요 |" + 절 배너 "| 1 | | 추진배경 및 필요성 |". □ 표제어는 "□ 사 업 명 : ", "□ 사업금액 : ", "□ 과업기간 : ", "□ 계약방법 : " 식 라벨형.

**인용 예시**
- "경영평가 위원용 GPTs 기능구현 방안 보고 / < '25. 2. 25.(화), 경영기획본부 AI디지털심화팀 >" [GPTs]
- "AI OCR(자체LLM)·외부API를 활용한 평가자료 자동화 결과 보고 / < '26. 3. 31.(화), 경영기획본부 AI디지털심화팀 >" [OCR]
- "경영평가 과제관리카드 AI 운영체계 구축·운영 계획(안) / < '26. 6. 15.(월), 경영기획본부 AI디지털심화팀 >" [과제카드] — '계획(안)' 접미
- "□ 개 요 … □ 주요 내용 … □ 주요 시사점" [Sovereign] — 절 어휘·벌려쓰기
- "「AI 공통기반 LLM구축을 위한 GPU 구매」 제 안 요 청 서 / 2026. 02. / 경영기획본부 AI디지털심화팀" [RFP-GPU] — 겹낫표 사업명 + 벌려쓴 문서유형
- "□ 사 업 명 : AI 공통기반 LLM구축을 위한 GPU 구매 / □ 사업금액 : 약 255,750,000원(VAT포함)" [RFP-GPU] — 라벨형 □

**빈도**: "< 날짜, 부서 >" 발신 줄 = 요약보고 전부(8/8) / 명사구+성격 접미 제목 = 전 파일 공통 / 절 어휘(배경·내용·효과·계획·시사점) 재사용 = 전 파일 공통 / 2글자 벌려쓰기 = 다수
